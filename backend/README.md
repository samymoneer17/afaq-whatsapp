# واتساب ويب — تطبيق ويب متكامل عبر neonize

تطبيق ويب مطابق لتجربة WhatsApp Web، مبني على **Python 3.12 + FastAPI + neonize**،
بواجهة عربية RTL كاملة مع وضع داكن وفاتح، وتحديث لحظي عبر WebSockets.

## المميزات

- **الربط**: كود إقران (Pairing Code) برقم الهاتف، أو رمز QR يظهر مباشرة في الواجهة.
- **مؤشر اتصال حي**: متصل / جارٍ إعادة الاتصال / غير مقترن + زر تسجيل خروج.
- **المراسلة**: نصوص، صور، فيديو، رسائل صوتية (تسجيل من المتصفح مع تحويل تلقائي إلى OGG)، مستندات، ملصقات WebP، واستطلاعات رأي.
- **التفاعلية**: رد باقتباس، تفاعل بالإيموجي (Reactions)، مؤشر الكتابة والتسجيل (ChatPresence)، علامات القراءة (✓✓) مع وضع التخفي.
- **وسائط المحادثات**: تنزيل تلقائي لكل الوسائط الواردة عبر `download_any()` إلى `downloads/media/` مع تشغيل مباشر داخل الفقاعات وزر تنزيل لكل وسائط.
- **الصور الشخصية**: جلب بأعلى دقة (`get_profile_picture` مع `preview=False`)، حفظ في `downloads/avatars/`، معاينة مكبّرة وزر تنزيل، عرض النبذة (About) وفحص `is_on_whatsapp`.
- **الحالات (Status)**: تبويب مستقل يلتقط حالات `status@broadcast` (نص/صورة/فيديو)، حفظ تلقائي في `downloads/statuses/` مع زر تنزيل.
- **القنوات (Channels)**: عرض القنوات المشترك بها، الانضمام عبر رابط/معرف، قراءة المنشورات والوسائط والتفاعل بالإيموجي.
- **المجموعات**: قائمة المجموعات المنضمة، الأعضاء والمشرفين، الانضمام عبر رابط دعوة.
- **بدء محادثة جديدة** بأي رقم هاتف دون حفظه في جهات الاتصال.

│   ├── css/app.css

## التشغيل السريع

```bash
cd whatsapp-web-app
python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
sudo apt install -y ffmpeg        # مطلوب إلزامياً بواسطة neonize
python main.py                    # أو: uvicorn main:app --host 0.0.0.0 --port 8000
```

ثم افتح: `http://SERVER_IP:8000`

## الربط بكود الإقران

1. أدخل رقمك مع كود الدولة (مثال: `966501234567`) واضغط **ربط**.
2. سيظهر كود من 8 خانات في الواجهة بعد لحظات.
3. على الهاتف: **الإعدادات ← الأجهزة المرتبطة ← ربط جهاز ← ربط برقم الهاتف بدلاً**، وأدخل الكود.

معالجة خطأ `client is nil` مدمجة: يفتح السيرفر `client.connect()` في خيط منفصل
وينتظر استقرار الاتصال + 2.5 ثانية قبل استدعاء `PairPhone`.

## ملاحظات مهمة

- **worker واحد فقط**: لا تستخدم `--workers 2` لأن عميل واتساب حالة مشتركة واحدة.
- **ffmpeg إلزامي**: تستدعيه neonize داخلياً عند `connect()` وعند تحويل الصوتيات والملصقات.
- **وضع التخفي**: من تبويب الإعدادات — يوقف إرسال علامات القراءة عبر `mark_read`.
- **إعادة الربط**: عند تسجيل الخروج تُحذف `whatsapp_session.sqlite3` وتظهر شاشة الربط من جديد، بينما يبقى الأرشيف في `app_data.db`.
- للحصول على HTTPS في الإنتاج ضع nginx/Caddy كوكسي أمامي أمام المنفذ 8000 (WebSocket يعمل عبر wss تلقائياً).
