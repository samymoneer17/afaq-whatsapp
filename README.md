# آفاق واتساب — تطبيق Flutter متصل بخادم WhatsApp حقيقي

تطبيق موبايل (APK) مطابق لتجربة **واتساب الأندرويد الرسمية**، مبني بـ **Flutter**،
ويتصل بخادمك الخاص (FastAPI + neonize) عبر REST + WebSocket ليصبح جهازك الرابع المرتبط بحسابك.

## ما الذي يفعله التطبيق؟

| الميزة | الحالة |
|---|---|
| ربط الجهاز بكود الإقران برقم الهاتف | يعمل |
| ربط الجهاز برمز QR | يعمل |
| محادثات فردية ومجموعات — نصوص | يعمل |
| إرسال صور وفيديو ومستندات وملصقات واستطلاعات | يعمل |
| تسجيل رسائل صوتية وإرسالها | يعمل |
| الرد باقتباس + التفاعل بالإيموجي | يعمل |
| مؤشر الكتابة والتسجيل (للطرف الآخر) | يعمل |
| علامات القراءة ✓ / ✓✓ / ✓✓ أزرق | يعمل |
| تنزيل الوسائط الواردة وعرضها داخل الفقاعات | يعمل |
| الحالات (Status) — نص/صورة/فيديو بعارض ملء الشاشة | يعمل |
| القنوات (Channels) — القراءة والتفاعل والانضمام والمغادرة | يعمل |

## عنوان الخادم الافتراضي

`http://SERVER_IP:8000` — يُكتب يدوياً في شاشة الربط عند أول تشغيل
النفسها أو من الإعدادات ← خادم الاتصال. أي عنوان يعمل: IP مباشر أو نطاق.

## البدء

1. انشر الباكند على السيرفر (راجع مجلد `whatsapp-web-app/` — سكربت `deploy_server.sh`).
2. ابنِ APK من هذا المشروع (راجع `BUILD_APK.md` — أبسط طريق: GitHub Actions).
3. ثبّت التطبيق، أدخل عنوان الخادم، ثم اربط حسابك بكود الإقران.

## ملاحظات أمان

- الخادم يعمل على HTTP بدون تشفير في هذا الإعداد — مناسب للاستخدام الشخصي التجريبي.
- وضع التخفي (`privacy_read`) يمنع إرسال علامات القراءة لحسابك من هذا الجهاز.
